Minecraft

Одиночный мир: Esc → «Открыть для сети» → укажи показанный порт. Bedrock-игроки могут зайти на Java-сервер через GeyserMC — тогда pal работает в полном режиме.

Через друзей Xbox: войди боту в его собственный аккаунт Microsoft, добавь его в друзья, открой мир для друзей. Хост и порт в этом режиме не нужны.

В Bedrock pal действует командами (/tp, /fill, /setblock, /give): в мире должны быть включены читы, а боту нужно дать права оператора. При входе через Microsoft код появится в журнале на дашборде — у бота должен быть свой аккаунт.

Лимиты

Когда лимит на исходе, pal пишет предупреждение в игровой чат несколько раз подряд. Остаток считается по заголовкам провайдера (x-ratelimit / anthropic-ratelimit), балансу OpenRouter, ошибкам «квота исчерпана» и твоему дневному бюджету. В шаблонах сообщений доступны {percent}, {reason}, {provider}.
