# MyPal: ИИ-компаньон для Minecraft на своих API-ключах

**Поддерживаемые версии Minecraft: Java 1.16.5 – 26.1 · Bedrock 1.16.201 – 1.26.60.** Верхняя граница растёт с обновлением библиотек (`npm update`); точный список — в панели и на `/api/versions`.

**Java и Bedrock. ПК, Android (APK или Termux) и iPhone (панель по Wi-Fi)** — см. [docs/PHONE_AND_BEDROCK.md](docs/PHONE_AND_BEDROCK.md).

Аналог MinePal. Бот заходит на сервер как обычный игрок: ходит за тобой, добывает, крафтит, строит, сражается, запоминает места и факты и отвечает в чате. Нейросеть ты выбираешь сам и меняешь ключи прямо в веб-панели, без перезапуска.

```
Ты (чат в игре / веб-панель / голос)
        │
        ▼
 AI CORE (LLM + личность + системный промпт)  ◄── Context Manager (только нужное из мира)
        │ tool calls                          ◄── Memory (факты, события, места)
        ▼                                     ◄── Planner / Task Manager
 ACTION SYSTEM (31 действие)  ──►  Mineflayer + Pathfinder + CollectBlock + PvP  ──►  сервер Minecraft
        ▲                                                                              │
        └──────── Reflex Engine (еда, самооборона, бегство, не утонуть) ◄──────────────┘
```

LLM решает, **что** делать (`collect_blocks("log", 10)`), а код решает, **как** это сделать (поиск пути, выбор инструмента, подбор дропа).

## Быстрый старт

Нужен **Node.js 22.13+** (используется встроенный `node:sqlite`, нативная сборка не требуется).

```bash
npm install
cp .env.example .env      # необязательно: ключи можно ввести в панели
npm start
```

Открой http://localhost:3000, затем:

1. **Настройки → Нейросеть.** Вставь ключ нужного провайдера, нажми «Проверить» и выбери его активным.
2. **Настройки → Minecraft.** Укажи хост и порт. Для одиночного мира: Esc → «Открыть для сети», порт возьми из сообщения в чате.
3. **Pals.** Укажи в поле «Хозяин» свой ник, тогда pal будет отвечать на все твои сообщения, а не только на обращения по имени.
4. **Дашборд → «Подключить».**
5. В игре напиши: `Alex, пойдём со мной`, `Alex, нарубь 10 брёвен`, `Alex, построй домик`, `стоп`.

Если на сервере включена лицензионная проверка (`online-mode=true`), боту нужен свой аккаунт: выбери `microsoft` в настройках авторизации. Для локальной сети и одиночного мира подходит `offline`.

## Провайдеры LLM (меняются на лету)

| id | Тип | Что это |
|---|---|---|
| `openai` | openai | OpenAI |
| `anthropic` | anthropic | Claude, через официальный SDK `@anthropic-ai/sdk` |
| `gemini` | gemini | Google Gemini |
| `openrouter`, `groq`, `deepseek` | openai | OpenAI-совместимые API |
| `ollama` | openai | Локальная модель, ключ не нужен |
| `custom` и любые свои | openai | LM Studio, vLLM, Together, свой прокси… |

* Каждому pal'у можно назначить своего провайдера: например, Alex работает на Claude, а Zoe на локальной Ollama.
* «Провайдер для памяти» — отдельная, обычно дешёвая модель для извлечения фактов из разговора.
* Ключи хранятся только локально, в `data/settings.json`. В панель они возвращаются в замаскированном виде (`sk-t…6789`). Пустое поле ключа при сохранении оставляет прежний ключ.
* Модель должна поддерживать **tool calling / function calling**.
* Для Claude в `data/settings.json` есть параметры `effort` (`low` по умолчанию, ради быстрых ответов в игре) и `fallbacks` (при отказе модели запрос автоматически уходит на запасную модель).

Изменить настройки можно и через API: `PUT /api/settings` с телом `{"llm":{"activeProvider":"gemini","providers":{"gemini":{"apiKey":"..."}}}}`.

## Что умеет pal

| Группа | Действия |
|---|---|
| Движение | `go_to_player`, `follow_player`, `go_to_coords`, `go_to_location`, `save_location`, `explore`, `stop` |
| Добыча | `collect_blocks` (проверяет, есть ли нужный инструмент), `pickup_items`, `break_block` |
| Крафт | `craft_item` (сам ставит или крафтит верстак), `smelt_item` (печь), `get_recipe`, `plan_crafting`, `list_variants` |
| Стройка | `build_house` (дом по параметрам), `build_custom` (свой чертёж от ИИ), `build_structure` (wall/platform/tower/box/pillar/pit), `place_block`, `break_block` |
| Бой | `attack`, `guard` (фоновая охрана игрока) |
| Инвентарь | `give_items`, `drop_items`, `equip`, `eat`, `store_in_chest`, `take_from_chest`, `sleep_in_bed` |
| Мышление | `inspect_surroundings`, `find_block`, `create_plan`, `update_plan_step`, `finish_plan`, `remember`, `wait` |

**Рефлексы** работают без LLM: автоеда при сытости ≤ 14, самооборона, отступление при низком здоровье или рядом с крипером, всплытие, когда кончается воздух. «Стоп» тоже обрабатывается мгновенно, без запроса к нейросети.

**Планировщик.** Сложную задачу («построй дом») pal разбивает на шаги через `create_plan`. Каждый шаг он отмечает выполненным только после того, как действие вернуло успех. Если шаги закончились, а план ещё не выполнен, pal продолжает его сам (до 6 продолжений). Задачи можно приостановить, возобновить или отменить на вкладке «Задачи».

**Память.** Есть три уровня:
* краткосрочная: последние реплики;
* эпизодическая: события;
* семантическая: факты.

Плюс именованные места. Значимые факты автоматически извлекаются из разговора каждые 6 реплик. Воспоминания можно смотреть, добавлять и удалять в панели.

**Поведение зависит от игрового режима.** Бот сам замечает `/gamemode` и коротко пишет в чат, как теперь будет действовать:

| Режим | Как себя ведёт |
|---|---|
| ⚔ Выживание | добывает, крафтит и плавит сам; перед стройкой собирает материалы; ест, убегает от крипера, защищается |
| ✨ Креатив | ничего не добывает: берёт любые блоки из инвентаря креатива (`get_item`), стройка сразу без сбора, может строить крупнее; не ест, не убегает, дерётся только в режиме охраны |
| 🗺 Приключение | не ломает и не ставит блоки (так устроен режим), но ходит, охраняет, сражается, крафтит, пользуется сундуками |
| 👻 Наблюдатель | только летает рядом и разговаривает; на просьбы что-то сделать предлагает сменить режим |

Нейросеть видит только инструменты, подходящие к текущему режиму. Если она всё же попросит недоступное действие, бот объяснит, почему так нельзя. В Bedrock режим тоже определяется. Там бот всё равно действует командами, но в выживании не раздаёт бесплатные предметы без просьбы.

**Постройки по описанию.** ИИ переводит просьбу в параметры `build_house`:

| Просьба | Параметр |
|---|---|
| «с подвалом» / «без подвала» | `basement` (по умолчанию без подвала), `basement_depth`, `basement_lined` |
| «двухэтажный» | `floors` (1–4), `floor_height` |
| «с двускатной крышей» / «с плоской» | `roof`: `gable` / `flat` / `none` |
| «из камня», «с бревенчатыми углами» | `wall_material`, `floor_material`, `roof_material`, `corner_material` |
| «без окон», «со стеклом» | `windows`, `window_material` |
| дверь и факелы | `door`, `door_material`, `torches` |
| размер | `width`, `length` |

Лестницы (`ladder`) в подвал и между этажами ставятся автоматически через люки. Порядок работы:
1. Сначала `dry_run=true`: бот выдаёт ведомость материалов и говорит, чего не хватает.
2. Бот собирает недостающее.
3. Стройка: сначала копает (подвал, расчистка), потом ставит блоки снизу вверх.
4. Перепроверка по чертежу: бот убирает блоки-подпорки и доставляет пропущенное.

Если постройка необычная (мост, башня с зубцами, ферма), ИИ рисует свой чертёж по слоям через `build_custom`.

**База крафтов** — см. [docs/RECIPES.md](docs/RECIPES.md).
* Каждая вариация хранится отдельной записью, с точной раскладкой по клеткам, сеткой 2×2 или 3×3 и станцией.
* Предметы проверяются по версии сервера.
* Есть таблицы плавки и рецепты незеритовых улучшений на столе кузнеца.
* Свои рецепты кладутся в `data/recipes/*.json`.
* `plan_crafting` строит всю цепочку крафта с учётом инвентаря.
* `npm run export-recipes -- 1.21.4` выгружает полную базу.

**Лимиты.** Когда лимит LLM на исходе, pal пишет в игровой чат `⚠ LIMITS ALMOST RAN OUT!` 4 раза подряд (число настраивается). Когда лимит закончился, пишет `⛔ LIMITS RAN OUT!`. Остаток определяется по:
* заголовкам провайдера (`x-ratelimit-*`, `anthropic-ratelimit-*`);
* балансу OpenRouter;
* ошибкам «квота/баланс исчерпаны»;
* своему дневному лимиту токенов или запросов, его можно задать для любого провайдера.

После предупреждения о том, что лимит закончился, pal **выходит из игры**. Это настройка `limits.leaveOnExhausted`, по умолчанию включена. Когда сменишь ключ или лимит обновится, подключи pal'а снова кнопкой.

Порог, число повторов, паузу и тексты сообщений можно поменять в «Настройках → Лимиты». Там же есть кнопка проверки. Расход за день виден на дашборде.

**Голос.** Кнопка 🎤 в чате и галочка «Озвучивать ответы» работают через Web Speech API браузера, ключи не нужны. Лучше всего — в Chrome или Edge.

## Структура

```
src/
  index.js            точка входа
  config.js           настройки и ключи (data/settings.json > .env > дефолты)
  db.js               SQLite: pals, memories, conversations, locations, tasks
  llm/                router.js + адаптеры openai.js / anthropic.js / gemini.js, usage.js (лимиты и расход)
  agent/              pal.js (мозговой цикл), manager.js, memory.js, tasks.js, context.js, prompts.js
  minecraft/          bot.js (Mineflayer + плагины), world.js (восприятие)
  bedrock/            body.js (подключение к Bedrock), actions.js (действия командами), protocol.js
  building/           blueprints.js (генераторы домов и чертежей), executor.js (стройка с проверкой)
  knowledge/          recipes.js (база крафтов под версию сервера)
  actions/            movement, gathering, crafting, building, interaction, agentic
  reflex/reflex.js    быстрые рефлексы
  server/server.js    REST + WebSocket
public/               веб-панель (без сборки)
test/                 npm test
```

### Как добавить своё действие

Добавь объект `{ name, description, parameters, run(pal, args) }` в любой файл из `src/actions/`. LLM увидит его автоматически. Если действие не удалось, бросай `ActionError` с понятным текстом: LLM прочитает его и попробует исправить причину.

### Как добавить провайдера с другим API

Создай класс с методом `chat({ system, messages, tools, maxTokens })`, который возвращает `{ text, toolCalls: [{id, name, args}] }`. Зарегистрируй его в `TYPES` в `src/llm/router.js`.

## Переменные окружения

`PORT` (3000), `HOST` (127.0.0.1; `0.0.0.0` — доступ с телефона по Wi-Fi), `PANEL_PASSWORD` (обязателен при `HOST=0.0.0.0`), `MC_EDITION` (`java`/`bedrock`), `BEDROCK_HOST`/`BEDROCK_PORT`/`BEDROCK_AUTH`/`BEDROCK_REALM`, `DATA_DIR` (`data`), `AUTOCONNECT=Alex,Zoe` (подключить при старте), `DEBUG=1` (лог в консоль), а также ключи и параметры из `.env.example`.

## Ограничения и что дальше

* Крыши — ступенчатые из полных блоков; ступеньки-stairs с ориентацией и импорт `.schem` пока не поддерживаются.
* Незеритовое улучшение на столе кузнеца бот знает, но пока не выполняет сам.
* Голос работает через браузер. Серверные STT/TTS (Whisper, ElevenLabs) можно добавить отдельным провайдером.
* Electron-обёртку можно добавить поверх: backend уже отделён от UI.
