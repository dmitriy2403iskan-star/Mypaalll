# Bedrock и телефон

## Два способа играть с pal'ом в Bedrock

### 1. Через GeyserMC (полный режим, рекомендуется)

Ставишь Java-сервер (Paper) с плагинами **Geyser** и **Floodgate**. Ты заходишь с телефона или консоли через Bedrock, а pal заходит как Java-бот. У pal'а остаются все умения: ходит, копает, крафтит, строит руками, дерётся, есть рефлексы. В панели выбираешь **Издание: Java** и указываешь адрес этого сервера.

### 2. Прямое подключение к Bedrock (режим команд)

**Издание: Bedrock.** Бот подключается напрямую к одному из вариантов:
- миру на телефоне или ПК, открытому для LAN;
- своему серверу BDS;
- Realm.

В Bedrock нет Mineflayer, поэтому pal действует **командами**. Нужны **включённые читы** в мире и **права оператора** для бота (`/op <имя бота>`). Что умеет в этом режиме:

| Умеет | Как |
|---|---|
| подойти, следовать, охранять | `/tp`, `/execute at <игрок> run tp`, `/kill @e[family=monster]` |
| строить дом и чертежи (подвал, этажи, окна…) | `/fill` и `/setblock`, ряды сжимаются в один `/fill` |
| выдать предметы | `/give` |
| время, погода, эффекты и т.п. | `run_command` (админ-команды вроде `/op`, `/stop`, `/ban` запрещены) |
| память, места, планы, рецепты, лимиты | так же, как в Java |

Чего не умеет: добывать блоки руками, крафтить, драться мечом. На такие просьбы pal честно отвечает, что в этом режиме так не может.

**Вход.**
- `offline` — для своего BDS с `online-mode=false`.
- `Microsoft` — для мира с телефона, Realms и онлайн-серверов. Код для входа появится в панели (баннер 🔑). Боту нужен **свой** Microsoft-аккаунт: тот же аккаунт, под которым играешь ты, второй раз в мир не зайдёт.

Поддерживаются версии Bedrock от 1.16.201 до 1.26.60 (через `bedrock-protocol`). Версия определяется сама.

## Запуск на телефоне

### Android (Termux)

1. Установи **Termux** из F-Droid или с GitHub. Версия из Google Play устарела.
2. В Termux:
   ```bash
   pkg install git -y
   git clone <адрес репозитория> mypal && cd mypal
   bash scripts/termux-setup.sh
   npm start
   ```
3. Открой в браузере телефона `http://localhost:3000`. Меню браузера → «Добавить на главный экран» — панель откроется как приложение.
4. Если играешь на этом же телефоне:
   - мир → «Видно игрокам в LAN» + читы;
   - в панели выбери Bedrock, хост `127.0.0.1`, порт `19132`, вход Microsoft;
   - нажми «Подключить» и выдай боту `/op`.
5. Не закрывай Termux: скрипт включает `termux-wake-lock`, чтобы Android не усыпил процесс, пока ты в игре.

Нативных модулей нет, поэтому установка работает на ARM без компилятора:
- Bedrock-сеть работает на чистом JS (`jsp-raknet`); нативный `raknet-native` заменён заглушкой в `stubs/`;
- база данных — встроенный в Node `node:sqlite`.

### iPhone

На iOS нельзя запустить Node.js. Поэтому MyPal запускается на ПК или ноутбуке, а панель открывается с iPhone по Wi-Fi:

```bash
HOST=0.0.0.0 PANEL_PASSWORD=придумай_пароль npm start
```

В консоли появится строка `С телефона: http://192.168.x.x:3000` — открой этот адрес в Safari и введи пароль. «Поделиться → На экран Домой» добавит иконку на экран.

Без `PANEL_PASSWORD` панель в сеть не открывай: через неё видны настройки и ключи.
