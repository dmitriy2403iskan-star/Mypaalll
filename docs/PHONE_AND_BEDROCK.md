# Bedrock и телефон

**Версии:** Java 1.16.5 – 26.1, Bedrock 1.16.201 – 1.26.60. У Bedrock нет версии «1.16.5»: самая ранняя поддерживаемая 1.16 — это 1.16.201. Команды бота подстраиваются под версию сервера. На старых Bedrock, до 1.19.50, используется старый синтаксис `/execute`; до 1.19.70 блоки в командах задаются числовыми значениями.

## Два способа играть с pal'ом в Bedrock

### 1. Через GeyserMC (полный режим, рекомендуется)

Ставишь Java-сервер (Paper) с плагинами **Geyser** и **Floodgate**. Ты заходишь с телефона или консоли через Bedrock, а pal заходит как Java-бот. У pal'а остаются все умения: ходит, копает, крафтит, строит руками, дерётся, есть рефлексы. В панели выбираешь **Издание: Java** и указываешь адрес этого сервера.

### 2. Прямое подключение к Bedrock (режим команд)

**Издание: Bedrock.** Бот подключается напрямую к одному из вариантов:
- миру на телефоне или ПК, открытому для LAN;
- своему серверу BDS;
- Realm.

В Bedrock нет Mineflayer, поэтому pal действует **командами**. Нужны **включённые читы** в мире и **права оператора** для бота (`/op <имя бота>`). Что умеет в этом режиме:

| Умеет | Как |
|---|---|
| ходить, следовать, охранять | своё тело без команд: физика, прыжки, поиск пути (команды — запасной вариант) |
| копать и ставить блоки | руками, как игрок (`collect_blocks`, `place_block`, `break_block`), сам подбирает дроп |
| крафтить | руками по рецептам сервера (`craft_item`): 2x2 в инвентаре, 3x3 у верстака; верстак найдёт, поставит или скрафтит |
| строить дом и чертежи (подвал, этажи, окна…) | в выживании — руками из своих блоков; в креативе — `/fill` и `/setblock` |
| выдать предметы | `/give` |
| время, погода, эффекты и т.п. | `run_command` (админ-команды вроде `/op`, `/stop`, `/ban` запрещены) |
| память, места, планы, рецепты, лимиты | так же, как в Java |

| драться | оружием из инвентаря (`attack`, `clear_hostiles`), охрана игрока (`guard`), самооборона — рефлекс |
| есть, надеть броню | `eat` (и сам ест, когда голоден), `equip` — броня и левая рука |
| сундуки, печь | `store_in_chest`, `take_from_chest`, `smelt_item` (печь найдёт, поставит или скрафтит) |
| отдать / выбросить / подобрать | `give_items` (подходит и бросает игроку), `drop_items`, `pickup_items` |
| сон | `sleep_in_bed` |

Всё это — без команд, как в Java. Команды бот использует только в креативе (`get_item`, стройка `/fill`) или если игрок прямо попросил (`run_command`).
Проверено на настоящем BDS 1.16.220, 1.19.1, 1.20.80, 1.21.50 и 1.26.60.

**Вход.**
- `offline` — для своего BDS с `online-mode=false`.
- `Microsoft` — для мира с телефона, Realms и онлайн-серверов. Код для входа появится в панели (баннер 🔑). Боту нужен **свой** Microsoft-аккаунт: тот же аккаунт, под которым играешь ты, второй раз в мир не зайдёт.

Поддерживаются версии Bedrock от 1.16.201 до 1.26.60 (через `bedrock-protocol`). Версия определяется сама.

## Запуск на телефоне

### Android — APK (проще всего)

1. Открой на телефоне страницу **Releases** репозитория и скачай `mypal-arm64-v8a.apk`. Если не уверен в архитектуре — `mypal-all.apk`.
2. Установи APK: разреши установку из браузера или файлового менеджера.
3. Запусти MyPal. При первом запуске приложение около минуты распаковывается, потом открывается панель.
4. Разреши уведомления. MyPal работает в фоне со значком в шторке, пока ты играешь в Minecraft.
5. Дальше всё как ниже: Bedrock, хост `127.0.0.1`, вход Microsoft, `/op` боту. Эти настройки в APK уже стоят по умолчанию.

Каждый пуш в репозиторий собирает новый APK на GitHub Actions (`.github/workflows/android.yml`). Как это устроено:
- внутри APK лежит Node.js из Termux (собран под Android) и урезанная копия приложения;
- фоновый сервис запускает Node, а окно приложения показывает панель;
- перед публикацией APK проверяется в эмуляторе Android: панель должна ответить, а HTTPS до API должен работать.

### Android (Termux)

1. Установи **Termux** из F-Droid или с GitHub. Версия из Google Play устарела.
2. В Termux:
   ```bash
   pkg install git -y
   git clone <адрес репозитория> mypal && cd mypal
   bash scripts/termux-setup.sh
   npm start
   ```
3. Открой в браузере телефона `http://localhost:3000`. Меню браузера → «Добавить на главный экран» — панель откроется как приложение.
4. Если играешь на этом же телефоне:
   - мир → «Видно игрокам в LAN» + читы;
   - в панели выбери Bedrock, хост `127.0.0.1`, порт `19132`, вход Microsoft;
   - нажми «Подключить» и выдай боту `/op`.
5. Не закрывай Termux: скрипт включает `termux-wake-lock`, чтобы Android не усыпил процесс, пока ты в игре.

Нативных модулей нет, поэтому установка работает на ARM без компилятора:
- Bedrock-сеть работает на чистом JS (`jsp-raknet`); нативный `raknet-native` заменён заглушкой в `stubs/`;
- база данных — встроенный в Node `node:sqlite`.

### iPhone

На iOS нельзя запустить Node.js. Поэтому MyPal запускается на ПК или ноутбуке, а панель открывается с iPhone по Wi-Fi:

```bash
HOST=0.0.0.0 PANEL_PASSWORD=придумай_пароль npm start
```

В консоли появится строка `С телефона: http://192.168.x.x:3000` — открой этот адрес в Safari и введи пароль. «Поделиться → На экран Домой» добавит иконку на экран.

Без `PANEL_PASSWORD` панель в сеть не открывай: через неё видны настройки и ключи.
