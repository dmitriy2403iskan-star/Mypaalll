# База крафтов

## Откуда берутся рецепты

1. **Автоматически, под версию сервера.** При подключении бот определяет версию (например 1.21.4). Рецепты верстака и инвентаря берутся из `minecraft-data` (PrismarineJS) для этой версии.
   - Каждая вариация — отдельная запись: `wooden_pickaxe`, `stone_pickaxe`, …, `oak_door`, `spruce_door`, … — все slab, stairs, boats, beds и так далее.
   - Если предмета нет в версии сервера, он считается несуществующим. Например, `crafter` недоступен до 1.21, а `cherry_door` — до 1.20.
2. **Плавка и стол кузнеца.** В `minecraft-data` их нет, поэтому они заданы таблицами в `src/knowledge/recipes.js`:
   - печь: руда → слиток, песок → стекло и так далее;
   - незеритовые улучшения: шаблон + алмазный предмет + незеритовый слиток.
3. **Свои записи.** Любые файлы `data/recipes/*.json` подмешиваются поверх. Сюда пойдёт твой TXT после конвертации.

## Формат записи

Формат соответствует разделу 24 спецификации:

```json
{
  "id": "minecraft:diamond_pickaxe",
  "name": "Diamond Pickaxe",
  "category": "tools",
  "introduced_in": "1.3",
  "recipes": [{
    "type": "crafting_shaped",
    "station": "crafting_table",
    "grid_size": [3, 3],
    "allowed_grid": "3x3",
    "requires_crafting_table": true,
    "pattern": [
      ["minecraft:diamond", "minecraft:diamond", "minecraft:diamond"],
      [null, "minecraft:stick", null],
      [null, "minecraft:stick", null]
    ],
    "slots": { "diamond": [0, 1, 2], "stick": [4, 7] },
    "output": { "item": "minecraft:diamond_pickaxe", "count": 1 },
    "recipe_introduced_in": "1.0",
    "recipe_removed_in": null
  }]
}
```

Пояснения к полям:
- `pattern` — матрица, строки сверху вниз, `null` — пустая клетка.
- `slots` — номера клеток сетки 3×3, от 0 до 8.
- `allowed_grid: "2x2"` — рецепт можно собрать в инвентаре. `"3x3"` — нужен верстак.
- Вместо `pattern` можно указать `ingredients` (список или `{предмет: количество}`); так задаются shapeless-рецепты.

Проверка версий: если версия сервера меньше `introduced_in`, предмет считается несуществующим. Рецепт с `recipe_introduced_in` или `recipe_removed_in` учитывается только в своём диапазоне версий.

## Полная выгрузка

```bash
npm run export-recipes -- 1.21.4
```

Команда создаёт `data/recipes-export-1.21.4.json`: все предметы с рецептами в этом формате, для 1.21.4 это 835 предметов и 1608 рецептов. Подходит для проверки или ручной правки.

## Что из этого использует ИИ

| Инструмент | Что даёт |
|---|---|
| `get_recipe` | точная раскладка по клеткам, станция, 2×2 или 3×3, сколько получится |
| `plan_crafting` | вся цепочка с учётом инвентаря: что добыть (и каким инструментом), что скрафтить или переплавить по порядку |
| `list_variants` | все вариации семейства: `pickaxe`, `door`, `slab`, `bed`… |
| `craft_item` | сам крафт. Mineflayer раскладывает ингредиенты по клеткам точно по рецепту, верстак бот ставит сам |
